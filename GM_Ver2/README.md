# GM_Ver2

OIBC 원본 배포 폴더에서 특성을 새로 만들고, 발전소별 예측, 시간외 앙상블 선택, 두 VPP 배정, 제출 파일 및 정산금 시나리오를 생성합니다. Python 3.12, CPU 4스레드로 실행했습니다.

```powershell
python -m pip install -r GM_Ver2/requirements.txt
python -m unittest GM_Ver2.test_ver2
python -m GM_Ver2.run --raw "C:/path/01_participant_dataset" --out "C:/path/local_run"
```

출력은 Git 저장소와 배포 폴더 밖의 별도 로컬 디렉터리를 사용합니다. 초기 실행은 약 3.3GB의 특성 캐시를 만듭니다. 같은 원본과 설정으로 중단 후 재개할 수 있습니다. 원본, 모델 설정, 학습 코드가 바뀌면 새 출력 디렉터리를 사용합니다.

## 모델과 시간 규칙

- 두 공급사의 17시 예보와 10시 대비 수정량, 일중 변화와 일평균, 공급사 간 차이, 태양고도 근사, 제공 메타데이터로 69개 특성을 생성합니다. 오프그리드 예보는 정각에 맞춰 넣지 않습니다. 발전량 실측은 타깃으로만 사용합니다.
- 시간은 우측닫힘 KST입니다. 하루는 01시부터 다음날 00시까지입니다. 실제 10~15시 구간은 종료시각 11~15시이며 이 다섯 구간에 K=3을 적용합니다. SMP와 K는 예측 입력에서 분리해 학습 가중치와 점수에 씁니다.
- 후보는 전체 이력 트리, 최근 365일 트리, 예보 변화량을 포함하는 깊은 트리, 소형 24시간 비인과 Transformer, 표본을 확대한 제곱오차 트리, 양방향 GRU입니다. Transformer는 익명 좌표 이웃과 전체 발전소의 문맥을 이용하며, 발전소 용량 정규화 Huber와 완전 관측 시각의 그룹·전체 절대오차를 결합합니다.
- 기본 실행은 트리당 최대 240,000개 주간 행을 표본 추출하며 제곱오차 트리는 520,000개까지 사용합니다. Transformer는 4 epoch, GRU는 6 epoch입니다. 고정 후보를 비교한 제한된 CPU 실험입니다. `--tree-rows`, `--epochs`, `--threads`로 별도 실험을 실행할 수 있습니다.
- 2024년 12월 24일부터 겨울, 3월, 4월, 5월 블록의 예측을 각 시작일 전일 17시까지의 실적으로 학습합니다. 라벨 수신 로그가 없어 타깃 종료시각을 기준으로 경계를 적용합니다. 스태커 학습도 매 블록 이전의 예측과 실적만 사용합니다.
- 단일 모델, 단순 평균, 비음수 합 1 전역 혼합, 피크별 혼합, 피크별 전체 편향 보정을 경쟁시킵니다. 혼합 가중치는 그룹합 SMP×K 가중 절대오차를 선형계획법으로 최적화합니다. 3·4월 각 달의 기준 트리 대비 상대 벌금 평균으로 최종 방식을 고르고 5월에 진단합니다.
- VPP는 시간외 발전소 잔차의 평균 벌금과 최악 운영월의 시간당 벌금을 함께 최소화합니다. 두 그룹은 각각 20,000kW 이상입니다. 제한 시간 MILP와 교환 탐색의 해 중 학습 목적함수가 좋은 유효 해를 저장합니다. 솔버 상태와 하한을 보고서에 남깁니다.

## 산출물

- `report.json`에는 후보별 벌금, 동등한 시간 경계를 적용한 트리+GA 비교, 최종 모델 설정, VPP 솔버 상태와 추정 정산금이 들어갑니다.
- `composition.csv`는 253개소 배정, `forecast.csv`는 두 그룹의 8,760시간 예측입니다.
- `winter/`, `march/`, `april/`, `may/`, `evaluation/`에는 모델 가중치, 학습 경계, 발전소별 예측이 들어갑니다.

정산금 시나리오는 5월 시간외 두 그룹 잔차의 연속 3일 블록을 공동 재표본하고 최종 재학습·재편성한 평가기간 예측량과 제공 SMP를 결합합니다. 매출은 시나리오 실적에 가격을 곱하고 벌금은 그룹별 절대오차에 `0.1 × SMP × K`를 적용합니다. P10~P90은 5월 오차 구조가 연간에 이전된다는 가정 아래의 시나리오 범위입니다. 이력에 여름과 가을의 완전 관측 구간이 없어 해당 계절의 오차와 연간 채점 결과는 검증할 수 없습니다.
