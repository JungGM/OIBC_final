# 예측 개선 후보의 공통 정산 시나리오

기존 GA 배정에서 경사하강법 예측, GRU Ver1 예측, 그리고 기존 예측의 KST 종료시각 01~04시를 0으로 보정한 후보를 비교했다. 세 예측에 동일한 SMP와 동일한 모의 실적을 적용했다. 모의 실적은 기존 예측과 2025년 4~5월의 시간 외 오차 60일을 기준으로 생성했다. 봄철 오차를 다른 계절에 옮기는 가정과 기존 예측 중심의 기준점이 결과에 영향을 준다.

| 조합 | 기본 시나리오 평균 정산 | 기존 대비 |
|---|---:|---:|
| 경사하강법 + GA | 6,327,330,987원 | 기준 |
| GRU Ver1 + 동일 GA | 6,317,236,872원 | −10,094,115원 |
| 경사하강법 + 동일 GA + 야간 보정 | 6,327,409,176원 | +78,189원 |

야간 보정은 오차 배율 0.5 시나리오에서 206,865원 감소했다. GRU Ver1은 봄 실적 진단에서 앞섰고, 기존 예측 중심의 연간 시나리오에서는 뒤졌다. 다음 비교에서는 여러 계절의 시간 외 예측과 서로 다른 기준 예측에서 만든 공통 시나리오를 함께 사용한다.

이 폴더는 후보 파일과 시나리오 결과를 보관한다. `night_corrected/`에는 야간 보정 후보, 루트 CSV에는 GRU 후보가 있다. 두 후보의 배정표는 기존 최종 GA 배정과 동일하다. 재현 명령은 `python -m GM_Ver1.compare_settlement --out <로컬 결과 폴더>`다.
