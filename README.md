# OIBC 개별 발전량 예측: 공통 학습 특징

대회 제공 예보와 익명 발전소 메타데이터로 7종 모델의 공통 입력을 만든다.
XGBoost, LightGBM, CatBoost, RandomForest, ExtraTrees는 시간별 표를,
GRU와 LSTM은 같은 열을 발전소별 24시간 배열로 읽는다.
현재 특징은 기존 38개와 파생 40개, 총 78개다.

## 입력과 생성 규칙

`prepare_features.py`는 기존 `backtest.py`가 대회 제공 파일에서 생성한
월별 전체 발전소·시간 예보 캐시를 읽는다. `feature_engineering.py`는
태양고도와 구름·UV의 조합, 두 예보 제공사의 불일치, 10시와 17시 예보의
변화 크기, 같은 목표일 예보 경로의 변화·변동·일평균, 결측 표시를 더한다.
일평균은 목표일 전날 17시까지 발행된 예보의 24시간 경로에서만 계산한다.
목표일 또는 발전소 경계를 넘어 이동 통계를 만들지 않는다.

`energy` 실적은 별도로 학습 정답으로만 결합한다. 실제 기상, 시험기간 실적,
미래 SMP는 입력 특징에 없다. 실적 결측은 학습에서 제외하고 0으로 채우지 않는다.
익명 위경도는 제공된 값 그대로 태양기하 계산에만 사용한다.

## 실행

Python 3.12 환경에 `requirements-individual.txt`를 설치한다.
원본 대회 데이터와 기존 백테스트 캐시는 로컬에 둔다.

```powershell
python prepare_features.py --cache <기존_백테스트_캐시> --out <로컬_특징_캐시>
python train_individual.py --data <대회_제공_데이터> --cache <기존_백테스트_캐시> --feature-cache <로컬_특징_캐시> --out <로컬_모델_폴더> --family all --trials 4
```

월별 특징 Parquet와 학습된 모델은 GitHub 밖의 로컬 경로에 만든다.
`--feature-cache`를 생략하면 같은 변환을 월별 읽기 시점에 계산한다.
준비된 캐시 사용 시 특징 이름·코드 해시·원본 캐시의 크기와 수정 시각을 확인한다.
7종은 같은 특징과 시간 순 구간을 사용한다. 각 모델의 결측 처리와 GRU/LSTM의
표준화는 학습 코드에서 수행하며, 표준화 통계는 해당 학습 구간에서만 구한다.
